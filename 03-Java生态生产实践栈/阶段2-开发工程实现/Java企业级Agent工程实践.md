# Java 企业级 Agent 工程实践（种子）

> 分级：🟡 生产最佳实践 ｜ 来源：`素材收集/03-nageoffer-ragent.md`、`素材收集/04-javaup-nexus-agent.md`、`素材收集/05-javaguide-ai.md`
> 定位：规划"阶段2 开发工程实现·Java 生态"的范例沉淀。两个开源项目（Ragent / Nexus Agent）共同构成 Java 侧企业级范式的"双参照系"。

## 一、架构分层（共识）

| 层 | Ragent 模块 | Nexus 模块 | 职责 |
|----|------------|-----------|------|
| 入口/编排 | `bootstrap` + `framework` | 用户入口 + 前置编排中心 | 启动装配、统一响应/异常、问题改写/拆分/歧义澄清 |
| AI 供应商隔离 | `infra-ai` | 知识底座 + 检索引擎 | Chat/Embedding/Rerank 客户端、档位/路由/降级 |
| 业务编排 | `rag` / `agent` | 三层执行器 + 智能体引擎 | RAG 问答、ReAct 执行、Skills、记忆、人工确认 |
| 系统支撑 | `system` | 工程化护栏 | 认证审计、流量保护、并发、全链路观测、安全沙箱 |
| 工具 | `mcp-server` | MCP/Skills | 基于 MCP 协议的外部工具即插即用 |

> **分层意图**：业务编排、AI 供应商差异、通用基础设施相互隔离 → 切换模型/向量库/对象存储时核心问答流程不重写（接口 + 注册表 + 配置隔离）。

## 二、执行范式（Workflow vs Agent 的工程化落地）

- **Ragent 双链路并存**：
  - v1 Workflow：路径写死（问题重写→意图识别→多路召回→组装生成），更快可控，适合知识助手。
  - v2 Agentic：路径由模型自定（知识检索/MCP 工具/Skills 皆为工具），ReAct 循环边推理边决策，适合需规划/操作的场景。
  - MCP 边界：客户端仅在 `agent` 模块装配；Workflow 不连 MCP。
- **Nexus 三层执行器**（优先级链，核心竞争力）：
  - 歧义追问 → 知识问答 → 开放式 Agent。
  - 模型回答前由"前置编排"做完所有确定性决策（路由判定/改写/拆分/域收缩/歧义检测），降低模型不确定性。

## 三、RAG 检索工程（答非所问多在召回阶段）

| 环节 | Ragent | Nexus | 通用要点 |
|------|--------|-------|---------|
| 召回 | 向量+关键词+知识图谱+联网 并行 | 向量+关键词 并行 | 多通道并行，单通道失败不影响主链 |
| 融合 | 去重 + RRF + Rerank | RRF + 可选 Rerank + Parent-Child 聚合 | RRF 融合多路得分 |
| 问题理解 | 查询映射/重写/拆分/树形意图/多库路由 | 五步前置编排 + 三级漏斗路由 | 改写与路由前置，降噪提准 |
| 防幻觉 | 回答溯源 + 用户反馈 | 证据预算裁剪 + 无证据短路 | 架构层杜绝编造 |

> JavaGuide 经验：Chunk 切粗、Query 未改写、关键词与向量未结合、重排缺失 → 逐项排查比换贵模型有用。

## 四、上下文与记忆治理

- **Ragent**：最近 N 轮 + 持久化摘要；Agent 侧三层上下文（控 Token 成本保留关键上下文）。
- **Nexus**：三种策略可切换（无记忆 / 滑动窗口 / 摘要压缩），便于对比调优。
- 共通：状态外化、执行中断恢复、长期记忆跨会话（呼应理论层 `1.2`）。

## 五、模型容错与流量保护

- **模型容错**：档位（ChatClient/EmbeddingClient/RerankClient）+ 首包探测 + 三态熔断降级；多候选自动切换，首包超时/空响应/异常触发降级。
- **流量保护**：Redis ZSET 公平排队 + Lua 原子抢占 + 过期信号量 + Pub/Sub 唤醒（Ragent）；分布式并发控制防突发压垮模型。
- **数据一致性**：RocketMQ 事务消息保障分块可靠执行；幂等；远程刷新用分布式锁 + 状态机。

## 六、可观测与安全护栏

- **可观测**：Trace Run/Node 耗时/输入输出/异常；管理端趋势/详情/配置 Diff（Ragent 基于 LangFuse）；Nexus 影子路由静默对比命中率/置信度/候选排名，形成优化闭环。
- **安全基础**：Sa-Token 认证、数据归属校验、上传限流、统一异常处理；工具调用写操作人工确认；MCP Schema 校验。
- **流式**：SSE 分事件输出（思考/正文/来源/推荐）；全局超时 + 客户端断开取消。

## 七、设计模式实战（Ragent 11 种，可提炼为 Java AI 工程规范）

策略（检索通道/后处理替换）、工厂（意图树/分块/回调创建）、模板方法（并行检索/模型请求）、注册表（意图节点）、装饰器（向量写入同步索引）、责任链（后处理/降级）、中间件（记忆注入/上下文压缩/技能遮蔽/工具批处理）、适配器（模型方言/MCP/MQ）、状态机（定时刷新）、事件回调（流式/SSE）、AOP（Trace/幂等/审计）。
