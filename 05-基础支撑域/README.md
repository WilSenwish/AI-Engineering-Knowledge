> 来源：xiaolincoding 图解系列（`素材收集/08-xiaolincoding-base.md`，含各系列栏目地图与真实链接）。
> 与其他层关系：理论层（01）是 AI 原理、双栈（02/03）是语言生态实践、横向支撑域（04）是跨阶段治理；**本层是它们的物理地基**——不理解 Redis/MySQL/网络/OS，就无法真正吃透 Ragent 的 Redis 公平排队、Nexus 的双引擎检索、或 K8s 下的 JVM 调优。

## 阅读建议

1. 先读本 README 建立"基础支撑→阶段4/5→双栈"的映射关系。
2. 按你当前卡点的工程问题选读：做 Agent 队列看 Redis；做审计/对话存储看 MySQL；做流式/网关看网络；做高并发执行器看系统(OS)。
3. 每个文档都给出"AI 工程师必须掌握清单"，可直接当自查表。
4. 深度原理以 xiaolincoding 原系列为准（文档内附栏目链接），本域只做"工程化视角"的提炼与衔接。
5. **原理精读（已回灌）**：每篇文档末尾的「五、原理精读」段，已各取 2 篇核心长文做源码级原理精读并回扣 AI 工程化——Redis（SDS/分布式锁 setnx）、MySQL（B+树/MVCC）、网络（HTTP/2/WebSocket）、系统（epoll/Reactor）。建议先读 一~四 的"用法映射"，再回看 五 的"底层因果"。
