## 一、采集目的（为什么基础支撑域进入本知识库）

本知识库纵向是"需求→开发→测试→部署→运维→治理"六阶段，横向是理论层 + Python/Java 双栈。
但 AI 工程化落地的**底层地基**——网络、操作系统、MySQL、Redis——此前仅在 Java 栈（Ragent 的 Redis ZSET 公平排队、Nexus 的 PGVector/ES、线程池+TTL）中被"用到"，缺乏系统性的基础支撑材料。
本批把 xiaolincoding 四大图解系列的主题地图收集进来，并映射到 AI 工程化场景，形成 `05-基础支撑域/`。

## 二、图解 Redis（18W 字 + 200 图）栏目地图

- 基础篇：什么是 Redis
- 面试篇：Redis 常见面试题
- 数据类型篇：数据类型和应用场景；图解 Redis 数据结构（String/List/Hash/Set/ZSet/Bitmap/HyperLogLog）
- 持久化篇：AOF 持久化；RDB 快照；大 Key 对持久化的影响
- 功能篇：过期删除策略 vs 内存淘汰策略；Redis 分布式锁（setnx）
- 高可用篇：主从复制；哨兵；Cluster 集群；Redlock 高可用分布式锁
- 缓存篇：缓存雪崩/击穿/穿透；数据库和缓存一致性

> 与 AI 工程化映射：ZSet→Agent 公平排队/延迟队列；Hash→Agent 记忆/用户画像；分布式锁→定时任务/并发去重；缓存问题→向量检索缓存防击穿。

## 三、图解 MySQL（20W 字 + 320 图）栏目地图

- 基础篇：执行一条 SQL 查询发生了什么；一行记录怎么存储
- 索引篇：索引面试题；从数据页看 B+ 树；为何用 B+ 树；单表不超 2000W 行；索引失效；count 区别；分页性能
- 事务篇：事务隔离级别实现（MVCC）；可重复读解决幻读了吗
- 锁篇：MySQL 有哪些锁；怎么加锁；update 无索引锁全表；死锁处理
- 日志篇：undo/redo/binlog 作用（how_update）
- 内存篇：Buffer Pool
- 架构篇：MySQL 架构

> 与 AI 工程化映射：索引/事务→对话与审计表；日志→数据恢复；架构→主从/分库分表（海量对话）。

## 四、图解系统/操作系统（16W 字 + 400 图）栏目地图

- 硬件结构：CPU 执行程序；存储层级；CPU 缓存一致性(MESI)；伪共享；软中断
- 内存管理：虚拟内存；malloc；内存回收；Linux 虚拟/物理内存管理；LRU 缓存污染
- 进程管理：进程线程基础；进程间通信；多线程同步；死锁避免；悲观/乐观锁；线程上限；线程崩溃
- 调度算法：进程调度/页面置换/磁盘调度
- 文件系统：文件系统全家桶；pagecache 与崩溃
- 设备管理：键盘输入链路
- 网络系统：零拷贝；I/O 多路复用 select/poll/epoll；Reactor/Proactor；一致性哈希
- Linux 命令：网络指标查看；日志分析 PV/UV

> 与 AI 工程化映射：线程模型→JVM Agent 执行器；多线程同步→并发 Agent + TTL；epoll/Reactor→高并发网关；一致性哈希→分布式缓存/分片。

## 五、图解网络（20W 字 + 500 图）栏目地图

- 网络基础：TCP/IP 模型；键入网址到网页显示；Linux 收发网络包
- HTTP 篇：HTTP 面试题；HTTP/1.1 优化；HTTPS RSA/ECDHE 握手；HTTPS 优化；HTTP/2；HTTP/3；HTTP vs RPC；HTTP vs WebSocket
- TCP 篇：三次握手/四次挥手；重传/滑动窗口/流量/拥塞控制；半/全连接队列；TCP 优化；面向字节流；断连/崩溃区别；QUIC(基于 UDP 可靠传输)；keepalive
- IP 篇：IP 基础；ping 原理

> 与 AI 工程化映射：SSE/WebSocket→流式对话(RuoYi/JEECG)；HTTP/2 多路复用→降低网关延迟；半/全连接队列→高并发服务调优；RPC→K8s 内部 gRPC。
