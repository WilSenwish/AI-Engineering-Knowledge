## 一、项目定位与价值主张

- **目标人群**：Java 后端校招/社招同学，需要 AI 项目做简历差异化；不想从 Python/算法切入，用熟悉的 Java 栈学 AI 应用层。
- **核心主张**："调个 API ≠ 生产级 Agent"。真正价值在于对每个环节的深入理解与工程化设计——文档解析、分块、问题改写、混合检索、幻觉控制、模型容错、链路追踪。
- **复杂度对标企业级**：多路检索、意图识别、模型容错、全链路追踪均为真实代码，非 PPT 架构图。

---

## 二、核心架构（模块化单体，7 个 Maven 模块）

| 模块 | 职责 |
|------|------|
| `infra-ai` | Chat/Embedding/Rerank/VLM 模型客户端、模型档位、路由、首包探测、健康状态与降级 |
| `system` | 用户认证与审计日志（各业务引擎之下的系统支撑域） |
| `rag` | RAG 问答、知识库、入库 Pipeline、意图树、检索、会话及管理端 API |
| `agent` | AgentScope ReAct 执行引擎，接入知识检索与 MCP 工具，支持技能、记忆、人工确认 |
| `bootstrap` | 启动装配层（仅启动类 + 主配置） |
| `framework` | 统一响应与异常、幂等、分布式 ID、MQ 适配、SSE 与跨节点流式取消等基础能力 |
| `mcp-server` | 基于 MCP Java SDK 的独立工具示例服务（天气/票务/销售/联网搜索） |

**分层意图**：业务编排、AI 供应商差异、通用基础设施相互隔离 → 切换模型/向量库/对象存储时核心问答流程不重写。

## 三、v1 vs v2 双链路并存

- **v1 Workflow 编排**：路径写死（问题重写→意图识别→多路召回→组装生成），更快更可控，适合问答类知识助手。
- **v2 Agentic 架构**：路径由模型自定（知识检索/MCP 工具/Skills 皆为其工具），ReAct 循环边推理边决策，链路更长非直线，适合需规划/操作的场景。
- **两条并存而非替代**："不是谁替代谁"。
- **MCP 边界**：MCP 客户端仅在 `agent` 模块装配（AgentScope 发现工具，地址配 `agent.mcp.servers`）；意图树 MCP 节点指定可用工具与确认规则；Workflow 不连 MCP。

## 六、可扩展性（接口 + 注册表 + 配置隔离）

- 模型：`ChatClient`/`EmbeddingClient`/`RerankClient` + 候选配置 → 进档位与候选路由，复用首包探测/健康检查/熔断。
- 存储：`VectorStore`/`ObjectStorageClient` 配置切换 → 知识入库与问答主流程不变。
- 检索：`SearchChannel`/后处理器 注册为 Spring Bean 设顺序 → 新通道参与并行召回，新处理器插入去重/融合/精排/富化。
- 入库：`IngestionNode`/`DocumentFetcher` 补充节点类型与配置。
- Agent：新人设与技能手册，或注册新中间件 → 复用 ReAct 循环/记忆/人工确认。

## 七、生产级特性对照（与市面 Demo 差异）

| 维度 | 常见 Demo | Ragent |
|------|-----------|--------|
| 检索 | 单路向量 TopK | 向量/关键词/图谱/联网 + RRF + Rerank |
| 问题理解 | 原问题直接检索 | 查询映射/重写/拆分/树形意图/多库路由 |
| 模型调用 | 单模型直连 | 档位/首包探测/熔断降级 |
| 工具 | 应用内函数调用 | MCP 协议/远程发现/Schema 校验/写操作人工确认 |
| 智能体 | 无/单轮函数 | ReAct 多轮/技能/执行中断恢复 |
| 入库 | 一次性脚本 | 可编排 Pipeline/节点日志/远程定时刷新 |
| 记忆 | 近期拼接 | 最近 N 轮 + 持久化摘要；Agent 侧三层上下文 |
| 运行保障 | 基础日志 | 分布式限流/幂等/事务消息/Trace 与审计 |
| 指标 | 调用量/耗时 | 基于 LangFuse 的链路质量/工具调用个性化指标 |
| 二次开发 | 流程写死 | 模型/存储/检索/入库/MCP 均有扩展接口 |

**流量保护**：Redis ZSET 公平排队 + Lua 原子抢占 + 过期信号量 + Pub/Sub 唤醒。
**模型容错**：多候选自动切换，首包超时/空响应/异常触发降级；三态熔断隔离故障节点。
**检索稳定性**：多通道并行，单通道失败不影响主链；召回/Rerank/TopK 分层控制规模。
**数据一致性**：RocketMQ 事务消息保障分块可靠执行；幂等；远程刷新用分布式锁 + 状态机。
**可观测**：Trace Run/Node 耗时/输入输出/异常；管理端趋势/详情/配置 Diff。
**流式**：SSE 分事件输出思考/正文/来源/推荐；全局超时 + 客户端断开取消。
**Agent 执行保障**：上下文水位裁剪压缩；长期记忆跨会话；写操作人工确认；执行中断。
**安全基础**：Sa-Token 认证、数据归属校验、上传限流、参数校验、统一异常处理。
