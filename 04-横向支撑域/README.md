## 与纵向阶段的关系
横向支撑域为 6 大纵向阶段（需求→开发→测试→部署→运维→治理）提供跨阶段通用能力，例如：
- 安全合规既在 `阶段6` 集中治理，也贯穿开发（工具鉴权）、部署（网关）、运维（审计）。
- 平台建设为 `阶段2/4` 提供可复用的中台能力。
- 成本 ROI 在 `阶段4/5` 量化，在 `阶段1` 做选型权衡。
