# 成本与 ROI（横向支撑域）

> 分级：🔴 待验证方案 ｜ 来源规划：ai-agent-book / nageoffer.com / 各实践栈部署与运维阶段

## 核心主题

1. **AI 项目成本构成**：模型调用（Token）、推理算力（GPU）、存储（向量库/对象存储）、工程人力。
2. **投入产出评估**：业务效果提升 vs 成本，量化 ROI。
3. **降本增效方案**：
   - 上下文压缩 / KV Cache / Prompt Caching 省输入 Token（理论层 `1.2`）。
   - 模型档位路由、缓存命中、量化（理论层 `1.3`、各栈 `阶段4`）。
   - 流量保护避免无效请求压垮模型（Ragent Redis 公平排队）。
4. **资源利用率优化**：GPU 池化、弹性伸缩、批处理（各栈 `阶段4/5`）。

## 一、AI 特有的成本工程维度（战略文章直接暴露）

传统业务没有、AI 场景必须补的工程能力（源自《战略洞察-Java工程能力移植与企业级AI应用形态》"AI 特有工程能力 / 成本管控"一节）：

1. **Token 消耗统计与按租户计费**：每次模型调用记录 input/output token、模型档位、归属租户；出账维度与多租户体系打通（OAuth2/JWT 租户标识）。
2. **模型配额管理**：按租户/用户分配模型配额（QPS、日调用量、并发上限），超限降级或排队（Redis 公平排队 / 网关限流）。
3. **闲时降配与批量推理优化**：低峰期切换到更小模型或降配实例；批量请求合并推理，开启 Prompt Caching / KV Cache / 上下文压缩提升命中与省输入 Token。
4. **成本归因与优化闭环**：按业务线/场景聚合成本，定位高成本链路（长上下文、冗余召回、未命中缓存），迭代 Prompt / 切片 / 缓存策略。
